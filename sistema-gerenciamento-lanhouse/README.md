# Nexus Gaming System

## Sobre o Projeto

O Nexus Gaming System é um sistema de gerenciamento para uma Gaming Lab / Lan House.

O sistema permite:

- Cadastro de clientes;
- Cadastro de computadores e consoles;
- Controle de aluguel de máquinas;
- Controle de sessões de uso;
- Sistema de pontuação e fidelidade;
- Promoções e combos;
- Controle de pagamentos;
- Rastreamento de utilização dos equipamentos.

---

## Objetivo

Desenvolver uma aplicação Java utilizando conceitos de:

- Programação Orientada a Objetos;
- Interfaces;
- Enumerações;
- JDBC;
- MySQL;
- Swing;
